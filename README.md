# Student Lifestyle and Stress Level Prediction

## Project Overview
This machine learning project predicts students' stress categories based on academic, lifestyle, and personal factors.

## Features
- Student information input through a Streamlit web app
- Machine learning-based stress level prediction
- Predicted stress category: Low, Medium, or High
- Model probability visualization, when supported

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit
- Jupyter Notebook

## How to Run

1. Install the required packages:

   `pip install -r requirements.txt`

2. Start the Streamlit application:

   `streamlit run app.py`

## Disclaimer
This project is for educational purposes only. It is not a medical or psychological assessment.
